Trust, but Verify the Label

Encrypted-traffic misclassification as the residual risk of deterministic policy gating
Muhammad Abdullah Aamir 23i-2538  ·  Haider Farooq Toor 23i-2542  ·  Muhammad Ibrahim Kiani 23i-2536
Research question

An AI agent's actions pass a correct policy check. Which violations still get through, and why?

18,758
encrypted flows, 23 timing features

01 · Problem

Labels decide what is allowed

Encryption hides payloads, so networks infer the application from flow timing. Language-model agents are now proposed to act on these labels. A check before execution reads the label, so it is only as correct as the prediction.

02 · Gap

Accuracy hides which errors matter

Classification studies report overall accuracy, not which mistakes change an enforcement decision. Pre-execution guards such as ToolGuard and AgentSpec assume the facts they read are correct.

03 · Contributions

What this work adds

  • Rebuilt the dataset's original protocol: the Random Forest beats the rebuilt C4.5 by at least 4.7 points at every timeout.
  • Paired test on identical agent proposals: violations fall from 30 to 6.
  • Traced every remaining violation to a restricted flow predicted as a more permissive class.

The policy (three levels)

P2P: block only
Streaming, file transfer: block or limit ≤ 1,024 kbps
Browsing, chat, email, VoIP: allow, block or limit ≤ 10,000 kbps

Why errors still leak

A correct gate executes only actions in Π(ŷ). A violation therefore needs

a ∈ Π(ŷ) \ Π(y)

which happens only when a restricted flow is predicted as a more permissive class.

08 · Probability-aware gate

Reading probabilities has a price

At a 10% over-restriction budget (ρ = 0.25) violations fall to 1, but only 43 of 50 tasks complete (89.6% retention). At 5% (ρ = 0.45) none are removed.

10 · Conclusion

Only as correct as the label

A deterministic gate stops most policy violations at microsecond cost, but it is only as correct as the label it reads. For an operator, the classifier metric that matters is the recall of restricted classes against permissive ones.

Next: recent traffic with capture-separated splits, stateful rules such as bandwidth budgets, and classifiers whose error costs follow the policy levels.
