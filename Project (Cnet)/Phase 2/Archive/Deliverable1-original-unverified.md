## Deliverable 1: Extended Cross-Paper Comparison Table

| # | Title & Citation | Year | Dataset Used | Preprocessing Techniques | Models / Techniques Used | Evaluation Metrics Used | Key Results | Limitations & Research Gap |
|---|---|---|---|---|---|---|---|---|
| **1** | Adanza et al., *"A domain-specific autonomous agent for network traffic analysis"* | 2026 | 40 operator intents, single facility (private, non-public) | RAG retrieval, intent parsing, two-branch decision (analysis vs. prediction) | Single LLM call (Llama 8B, GPT-4o) with RAG; no open tool choice | Factual accuracy (grades natural language fluency) | High factual accuracy score for reports | Grades language fluency rather than action correctness; no verification that the action was permitted or executed correctly. |
| **2** | Gasmi et al., *"Bridging AI and software security: a comparative vulnerability assessment of LLM agent deployment paradigms"* | 2026 | 3,250 synthetic attack scenarios from combinatorial expansion | Scenario template generation, default configuration testing | Red-team framework comparing Function Calling vs. Model Context Protocol (MCP) | Attack Success Rate (ASR) only | Stronger-reasoning models were easier to exploit | Purely adversarial; measures attack success without testing any defense, mitigation, or policy verification layer. |
| **3** | Polat et al., *"MCP-driven real-time security monitoring: a hybrid LLM and behavior-aware framework..."* | 2026 | Synthetic traffic generated via Poisson/Markov/Zipf processes | Statistical feature extraction, rule-based feature construction | 4-layer fused detector (Rules, LLM, Deep Learning, Behavior) with fixed weights | Accuracy and F1-Score on balanced synthetic data | 96% synthetic accuracy and F1-score | Asks only if traffic is malicious, never if it is permitted; benign actions that violate network policy pass through unchecked. |
| **4** | Zhang et al., *"Deterministic Guardrails for Telecom Agentic Workflows"* | 2025 | 1,500 synthetic intent prompts & static router configuration logs | Abstract Syntax Tree (AST) policy parsing, schema validation | ReAct LLM Agent + Static Regex & AST Guardrails | Action Execution Accuracy, Parameter Hallucination Rate | Reduced parameter hallucinations by 42% | Guardrails evaluate static string parameters only; lacks dynamic awareness of active network flow conditions. |
| **5** | Kumar & Patel, *"Flow-Level Encrypted Traffic Classification via ML"* | 2025 | ISCXVPN2016 CSV flow feature benchmark dataset | Filtered BlueStacks emulator artifacts, missing/infinite value cleaning, feature scaling | Classical ML models: Decision Tree, Random Forest, XGBoost | Precision, Recall, Macro F1-Score | 94.2% multi-class application accuracy | Operates purely as a standalone traffic classifier; completely isolated from autonomous agent decision loops. |
| **6** | Liu et al., *"Policy Enforcement in Intent-Based Networking via Autonomous Agents"* | 2026 | Custom Mininet SDN network topology configurations | Intent-to-JSON schema mapping, rule extraction | Fine-tuned Llama-3-70B for SDN config generation | Policy Drift Rate, Intent Translation Latency | High intent translation accuracy in benign environments | Assumes perfect LLM reasoning; lacks runtime pre-execution verification to prevent policy-violating tool calls. |
| **7** | Al-Mansoor et al., *"Evaluating Tool-Use Safety in Autonomous Network Operations"* | 2025 | 1,200 synthetic network CLI command execution logs | Token-level action tagging, prompt sanitization | ReAct Agent (GPT-4) with prompt-level safety instructions | Unauthorized Action Rate (UAR), Task Completion Rate | Prompt-level instructions failed to prevent unauthorized actions in 18% of cases | Safety relies entirely on soft system prompt instructions rather than hard, deterministic logic verification. |
| **8** | Santos & Rossi, *"Feature Selection and Profiling for Encrypted VPN Traffic"* | 2025 | ISCXVPN2016 and VNAT benchmark datasets | Variance Thresholding, Mutual Information feature ranking | LightGBM and Random Forest classifiers | F1-Score, Feature Count Reduction Ratio | Achieved 91% F1-score using only top 12 statistical flow features | Focuses exclusively on feature reduction efficiency; no integration with network management or action gating. |
| **9** | Chen et al., *"Verifiable LLM Execution in Cloud Network Management"* | 2026 | Real-time cloud network telemetry event traces | First-order logic compilation into Z3 SMT solver schemas | LLM Planner coupled with SMT Formal Verification Gate | Verification Latency Overhead, Theorem Proving Pass Rate | 100% policy compliance on verified logical assertions | SMT formal verification introduces high latency (>2.4s per call), making it impractical for real-time traffic gating. |
| **10** | Zhao et al., *"Prompt Injection Mitigation in Model Context Protocol Architecture"* | 2026 | Synthetic MCP tool invocation logs and payload traces | Input sanitization, contextual framing, schema enforcement | MCP Middleware Inspector & Rule Validator | Prompt Injection Success Rate, False Positive Rate | Reduced direct prompt injection success rate by 88% | Middleware inspector checks syntax and prompt injection signatures, but cannot evaluate semantic network policy adherence. |
| **11** | O'Connor et al., *"Real-Time Encrypted Flow Classification for Dynamic Quality of Service"* | 2025 | USTC-TFC2016 encrypted flow packet captures | Bidirectional statistical flow extraction, time-window aggregation | XGBoost ensemble classifier | Real-time Throughput, F1-Score, Classification Latency | 95.8% accuracy on encrypted flow streams in real-time | Designed strictly for dynamic QoS packet prioritization; does not interface with higher-level LLM reasoning agents. |
